      Panduan pengelola

      Agar data tidak hilang lagi

      1. Simpan berkas di folder yang benar

        Unggah ke folder Google Drive sesuai kategorinya, misalnya 4. Pengumpulan Data / DTSEN. Hindari menyimpan data penting hanya di chat atau folder pribadi.

      2. Salin tautan berbagi

        Di Drive: klik kanan berkas → Bagikan → Salin link. Untuk data pribadi warga, pilih Dibatasi agar hanya orang yang diberi izin yang bisa membuka.

      3. Catat di SDDS

        Buka repositori GitHub, edit data/katalog.js, salin satu blok data, ganti judul, tautan, dan tanggal, lalu Commit. Situs ikut berubah dalam ±1 menit.

      Butuh berkas berlabel “Terbatas”?

      Berkas seperti DTSEN desil, RDDK, dan data per RT memuat data pribadi warga. SDDS hanya menyimpan tautannya — izin buka tetap diatur di Google Drive.
